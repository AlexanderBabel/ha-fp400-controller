Pair the FP400

In Home Assistant open Settings → Devices & services → Matter → the FP400 → Share device and paste the fresh code here. Don't reset the sensor or remove it from any app.

Then

Add the Aqara FP400 (Matter, separate controller) integration with the default controller address ws://127.0.0.1:5581/ws.

Keep this app running: it holds the FP400's extra pairing. Its data belongs in your backups.
